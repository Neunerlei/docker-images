The information about the docker images can be derived of the docs in `../../docs`. Each image type has it's own documentation. The images use the same basic logic and structure, so the skill should combine those into a general section, with dedicated resources for each skill.

If someone wants to use the legacy `php` image, the skill should make it absolutely clear that it is deprecated and that the `php-nginx` image should be used instead. It is no longer maintained and will not receive any updates or security fixes.

The `../../docs/migration` directory contains a migration guide for changes inside the images. Since the images are bound to the versions of the software they ship, the notes in there might help debugging and troubleshooting issues. The skill should provide a link to the migration guide and highlight the most important changes.
